## Urgency ranking (top 5 fixes across all schools)

1. **UIUC second-choice eligibility.** Illinois lists Computer Science (including all CS blended majors) as unavailable as a second choice, which may knock out the planned Stats & CS / Math & CS fallback. Resolve this before submitting, since it changes which second-choice essay gets written.
2. **Purdue "Why CS" answers half the prompt.** The response omits the required campus clause and names no Purdue anchor, leaving about 60 of 250 words unused. This is a required-clause miss, the highest-severity drafting defect in the set.
3. **UMD Prompts 1 and 5 repeat the idli-sambar motif**, and Prompt 5 spends its free space on sleep and lost keys. Two selection-level changes recover a B-grade short-answer set.
4. **MIT and Purdue each carry a factual risk.** MIT Response 2 claims an "A-Level" status that conflicts with the Indian-board/IPQ context; MIT Response 3 names an unverified MIT group; and Purdue `research.md` cites the wrong faculty URL for Ming Yin. Fix the facts before any name or credential is submitted.
5. **Virginia Tech names no VT resource in any of the four answers.** The file supplies verified options, so this is free points that require no new facts.
