# Aditya Balaji: Supplemental Applications

This directory is the working source for university-specific writing. The older combined draft remains in `aditya/drafts/supplement-essay-drafts-v1.md` as an archive.

`combined-supplement-essays.md` is the generated reading copy. Do not edit it directly. After changing an individual university file, rebuild it with:

```sh
sh aditya/supplements/sync-combined.sh
```

Each university file contains the current prompts, draft responses, word-count targets, unresolved fact checks, and school-specific research. The live application portal controls final wording and limits.

## Editing rule

Work in the university file, then update the combined archive only after a university set is approved. Never copy a response into another school without checking what new function it performs there.
