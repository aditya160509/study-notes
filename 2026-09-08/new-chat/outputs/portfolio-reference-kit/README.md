# Interactive desktop portfolio reference kit

This folder documents the public structure and assets observed from the reference portfolio at:

- Outer shell: https://yoshik-pc.vercel.app/
- Inner portfolio: https://yoshik-portfolio.vercel.app/

The goal is to build an original portfolio inspired by the interaction model, using your own identity, copy, projects, images, sounds, and visual treatment.

## Included

- `IMPLEMENTATION.md` — detailed recreation/customization guide.
- `ASSET-INVENTORY.md` — downloaded public reference assets and their roles.
- `assets/outer/` — public 3D models, textures, audio, and the outer JavaScript bundle.
- `assets/inner/` — public portfolio CSS, page bundle, and Ubuntu/Yaru icon assets.
- `source/inner-index.html` — captured public HTML shell for reference.

## Important usage note

These files were downloaded from publicly reachable URLs for reference. Before publishing, replace the reference person's content, links, branding, icons, music, and 3D artwork with assets you own or have permission to use. The safest route is to keep the architecture and interaction ideas while creating a new visual identity.

## Recommended direction

Build the inner portfolio first as a normal responsive website. Add the simulated desktop second. Add the 3D computer shell last, only if it improves the experience on your target devices.
