# SAT Math Formula Cheat Sheet

## Algebra

- Slope: `m = (y₂ − y₁)/(x₂ − x₁)`
- Slope-intercept form: `y = mx + b`
- Point-slope form: `y − y₁ = m(x − x₁)`
- Quadratic formula: `x = (−b ± √(b² − 4ac))/(2a)`
- Vertex x-coordinate: `x = −b/(2a)`
- Exponent rules: `aᵐaⁿ = aᵐ⁺ⁿ`, `aᵐ/aⁿ = aᵐ⁻ⁿ`, `(aᵐ)ⁿ = aᵐⁿ`

## Geometry

- Rectangle area: `A = lw`
- Triangle area: `A = ½bh`
- Circle circumference: `C = 2πr`
- Circle area: `A = πr²`
- Pythagorean theorem: `a² + b² = c²`
- 45-45-90: legs `x`, hypotenuse `x√2`
- 30-60-90: short leg `x`, long leg `x√3`, hypotenuse `2x`
- Rectangular-prism volume: `V = lwh`
- Cylinder volume: `V = πr²h`
- Sphere volume: `V = ⁴⁄₃πr³`
- Cone/pyramid volume: `V = ⅓Bh`

## Statistics and probability

- Mean: `sum of values / number of values`
- Percent change: `(new − original)/original × 100%`
- Probability: `favorable outcomes / total outcomes`
- Standard deviation measures spread; adding the same constant to every value does not change it.
