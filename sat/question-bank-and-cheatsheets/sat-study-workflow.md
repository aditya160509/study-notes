# SAT Study Workflow

1. Take one full-length Bluebook test or downloadable practice test under timed conditions.
2. Record every missed question by section, domain, skill, and error type.
3. Use the Student Question Bank to filter targeted official questions.
4. Review the explanation and write the rule or reasoning that would prevent the error.
5. Re-test the same skill after 2–3 days, then take a mixed timed module.
6. Repeat with progressively harder questions; keep a running error log.

The live official question banks are linked in `sat/README.md` because College Board serves them through interactive web apps rather than a public downloadable bulk file.
