# 07 — Study Plans

## Before you start
1. Take the **free official practice test** (englishtest.duolingo.com/practice).
2. Write down your score range and weakest subscore.
3. Pick a target score from your universities' minimums + 5–10 points of buffer.

---

## 4-week plan (60–90 min/day)

### Week 1 — Baseline and format
| Day | Focus |
|---|---|
| 1 | Practice test #1. Read [01-format-and-scoring.md](01-format-and-scoring.md). |
| 2 | Reading types ([02-reading.md](02-reading.md)). 50 Read and Select words. |
| 3 | Listening types ([03-listening.md](03-listening.md)). 10 dictation sentences. |
| 4 | Writing templates ([04-writing.md](04-writing.md)). 3 photo descriptions. |
| 5 | Speaking templates ([05-speaking.md](05-speaking.md)). Record 3 answers. |
| 6 | Vocab + grammar ([06](06-vocabulary-and-grammar.md)). |
| 7 | Practice test #2. Review mistakes. |

### Week 2 — Reading and listening
Daily: 3 Read and Complete passages · 10 dictation sentences · 1 Interactive Listening summary (75 s timer) · 15 new words · 1 Interactive Reading set (alternate story and factual texts, 7–8 min timer). End with practice test #3.

### Week 3 — Writing and speaking
Daily: 3 timed photo descriptions · 1 Interactive Writing (5+3 min) · 1 Writing Sample · 3 recorded speaking answers (one Interactive Speaking set of 6) · replay and cut fillers. End with practice test #4.

### Week 4 — Full mocks and fixes
| Day | Focus |
|---|---|
| 1, 3, 5 | Full mock in real conditions (second phone set up, no breaks) |
| 2, 4 | Drill your 2 weakest question types only |
| 6 | Tech rehearsal: room, lighting, phone camera, internet |
| 7 | Light review, sleep well. Test day. |

## 2-week crash plan (2–3 h/day)
- **Days 1–2:** practice test, read files 01–05.
- **Days 3–6:** morning reading/listening drills, evening writing/speaking with templates.
- **Days 7–12:** one full mock per day + 1 h fixing the weakest area.
- **Day 13:** tech rehearsal + light review. **Day 14:** test.

Book when your last 2 practice scores are **at or above your target**. You can buy up to 3 tests in any rolling 30 days, so a backup attempt is possible. Leave at least 2–3 weeks before your earliest application deadline.

## 07.01 Diagnose before you plan

Do not start with a generic timetable. Start with a **score profile**.

### Step 1 — Take a full practice test

Record:

| Data | Your result |
|---|---|
| Overall score range | |
| Literacy | |
| Comprehension | |
| Conversation | |
| Production | |
| Reading | |
| Writing | |
| Listening | |
| Speaking | |

### Step 2 — Find the binding constraint

| Pattern | Likely bottleneck | First fix |
|---|---|---|
| Low Literacy, strong Comprehension | Writing accuracy / spelling | Proofreading + word forms |
| Low Literacy, weak Comprehension | Reading speed / vocabulary | C-tests + AWL |
| Low Comprehension, strong Literacy | Listening detail / inference | Dictation + Interactive Listening |
| Low Conversation, strong Production | Interactive Listening tone | Reply-function drills |
| Low Production, strong Literacy | Speaking fluency | 4/3/2 drill + recording |
| Low Production, weak Literacy | Grammar across both | Sentence-level accuracy |
| All subscores around 110–120 | Range and stamina | Full mocks + complex structures |
| One subscore 10+ below others | Specific task weakness | Drill that task only for a week |

### Step 3 — Choose a plan length

| Time available | Plan | Realistic gain |
|---|---|---|
| 8+ weeks | 8-week build | +15–25 points |
| 4 weeks | 4-week standard | +10–20 points |
| 2 weeks | 2-week crash | +5–15 points |
| 5–7 days | 1-week emergency | +0–10 points; focus on format and timing |

**Be honest:** a 7-day plan cannot transform a 95 into a 130. It can stop you losing marks you already know how to earn.

## 07.02 The 8-week build

### Weeks 1–2 — Foundations

| Area | Daily | Weekly output |
|---|---|---|
| Vocabulary | 12 AWL words + word families | 1 paragraph using 10 words |
| Reading | 2 C-tests + 50 Read and Select words | 1 Interactive Reading set |
| Listening | 10 dictation sentences | 1 Interactive Listening set |
| Writing | 1 photo description | 1 Interactive Writing |
| Speaking | 3 recorded 35-second answers | 1 full 90-second answer |

### Weeks 3–4 — Task mastery

- Alternate days: **reading/listening** vs **writing/speaking**.
- Introduce strict timers for every task.
- Start a **weekly full mock**.
- Build a personal error log with categories, not just "mistake".

### Weeks 5–6 — Integration

- Two full mocks per week.
- On non-mock days, drill only the **two weakest task types**.
- Write one Writing Sample and record one Speaking Sample weekly; review them as application material.
- Increase speaking practice to 20 minutes daily.

### Weeks 7–8 — Performance

- Three full mocks per week under real conditions (phone camera, room scan, no breaks).
- Taper vocabulary to review only.
- Rehearse test-day setup twice.
- Final week: no new material; sleep, light review, and timing drills.

## 07.03 The 1-week emergency plan

Use this only if the test is already booked and you cannot move it.

| Day | Morning (90 min) | Evening (60 min) |
|---|---|---|
| 1 | Full practice test; identify 2 weakest types | Read 01 + 08; set up phone/second camera |
| 2 | 30 Read and Select + 2 C-tests + 1 Interactive Reading | 1 Interactive Writing + proofread |
| 3 | 10 Listen and Type + 1 Interactive Listening | 3 photo descriptions + 1 Writing Sample |
| 4 | 2 Interactive Reading + 100 vocabulary review | 6 Interactive Speaking answers recorded |
| 5 | Full mock | Review error log; redo weakest type |
| 6 | Timing drills only; tech rehearsal | Light review; sleep early |
| 7 | Test day | — |

**Rules for the emergency week:**

- Do not learn a new grammar topic.
- Do not memorise full essays.
- Practise the **first 10 seconds** of every speaking answer; that is where most fluency collapses.
- Rehearse the room scan and ear scan until boring.

## 07.06 Mock-test protocol

A mock is only useful if it is realistic.

**Before:**

- Same computer, same phone position, same room.
- No headphones, no notes, no second screen.
- Close all apps and notifications.
- Do the room scan and ear scan.
- Start at the same time of day as your real test.

**During:**

- No pauses.
- Use the real timers.
- Speak aloud, even if it feels awkward.
- Do not stop to look up a word.

**After:**

| Question | Answer |
|---|---|
| Overall score | |
| Weakest subscore | |
| Task with most lost marks | |
| Root cause (vocab / timing / grammar / fluency) | |
| One drill for tomorrow | |
| One thing that worked | |

**Do not** immediately take another mock. Fix the root cause first; otherwise you reproduce the same score.

## 07.07 Breaking a plateau

| Symptom | Likely cause | Intervention |
|---|---|---|
| Score stuck at 115–120 | Accuracy in basic grammar and spelling | 14 days of sentence correction + proofreading |
| Score stuck at 125–130 | Limited range; safe answers | Force complex structures and less common vocabulary |
| Reading high, writing low | Speed without accuracy | Slow down; check every ending |
| Writing high, speaking low | Fluency anxiety | Daily recording; 4/3/2 drill |
| Listening high, reading low | Vocabulary breadth | AWL + news reading |
| Scores fluctuate ±10 | Test-day conditions / sleep | Full mocks at the same time of day |
| Strong practice, weak real test | Setup stress or proctoring anxiety | Rehearse setup; take a low-stakes retake |

**Plateau rule:** change **one variable at a time** for two weeks. If you change everything, you cannot tell what worked.

## 07.08 Booking timeline

| Weeks before deadline | Action |
|---|---|
| 10–12 | Confirm the university accepts the DET and its minimums |
| 8–10 | Take a baseline test; start the 8-week plan |
| 6 | First full mock; adjust target |
| 4 | Book the test if your last two mocks are near target |
| 3 | Full mocks under real conditions |
| 2 | Fix the weakest task; tech rehearsal |
| 1 | Light review; no new material |
| 0 | Test day |

**Leave room for a retake.** A rolling 30-day limit means a second attempt may not be possible immediately after a disappointing score. If the deadline is tight, book earlier than feels comfortable.

**Test-credit warning:** a purchased test credit is valid for **21 days**. Buy when you are ready to test, not months in advance. If you are planning a retake, check the current bundle rules before purchasing.
