## Error types

| Code | Type | Example |
|---|---|---|
| ART | Article | *I went to university* vs *I went to the university* |
| PL | Plural/countability | *many information* → *much information* |
| TNS | Tense | *He have written* → *He has written* |
| AGR | Subject–verb agreement | *The list of items are* → *is* |
| PREP | Preposition | *depend of* → *depend on* |
| WF | Word form | *success* vs *successful* vs *succeed* |
| SP | Spelling | *recieve* → *receive* |
| PUN | Punctuation | missing comma/ question mark |
| COH | Coherence | no topic sentence; ideas jump |
| REL | Task relevance | off-topic or only partly answers |
| LEX | Vocabulary choice | *make a photo* → *take a photo* |
| SPEAK | Fluency/pronunciation | long pause; unclear ending |

## How to write a useful rule

Bad: "Be careful with articles."
Good: "Use **the** when the noun is specific or already mentioned; use **a/an** for one of many."

Bad: "Use better vocabulary."
Good: "Replace *important* with *crucial/significant/vital*, but only when it fits the sentence."

## Ten-minute review routine

1. Read the last 10 rows.
2. Cover the "correct version" column.
3. Say the correction aloud.
4. Write one new sentence using the rule.
5. Mark the row "re-tested" only if you got it right in a new sentence.
