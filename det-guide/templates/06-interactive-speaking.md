# Template 06 — Interactive Speaking (35 seconds × 6–8)

**Task:** A conversation with a DET character. **6–8 questions**, **35 seconds per answer**, usually **two topics**.
**Goal:** 25–35 seconds of relevant, expanded speech per answer. Click **Record** immediately.

## The one rule

Do **not** give one-sentence answers. One sentence is 3–5 seconds; you need 25–35. Use **OREO** to expand every answer.

## OREO skeleton

```text
[O — OPINION]
I think / Personally, I believe ______________.

[R — REASON]
One main reason is that ______________.

[E — EXAMPLE]
For example, ______________.

[O — OUTCOME]
As a result, ______________. / That is why I ______________.
```

## One answer, timed

| Part | Time | Content |
|---|---|---|
| Opinion | 0–5 s | Direct answer |
| Reason | 5–15 s | Why you think it |
| Example | 15–27 s | A specific example |
| Outcome | 27–35 s | Wrap-up |

If you only have 20 seconds of content, add a **contrast**: *"Some people might say …, but I think …"*

## Topic map

## Phrase bank

**Opinion**
- Yes, I definitely think …
- Personally, I believe …
- I'm not completely sure, but I'd say …
- It depends, but generally …

**Reason**
- One main reason is that …
- The main thing is …
- This is largely because …
- Another factor is …

**Example**
- For example, when I was at school, …
- In my country, for instance, …
- A good example is …
- I remember once …

**Outcome**
- As a result, …
- That is why I think …
- So overall, …
- Which is why it matters.

**Buying time**
- That's an interesting question.
- I've never really thought about that, but …
- Off the top of my head, I'd say …
- Let me think for a second …

## Model answer (33 seconds)

**Question:** Should schools focus more on creativity than academics?

> Yes, I think schools should definitely focus more on creativity, not just academics. One main reason is that creative subjects teach students how to solve problems in different ways. For example, when I was at school, we had an art project where we had to design a solution for reducing waste in our community. It made us combine artistic thinking with practical problem-solving. As a result, I started looking at everyday problems more creatively, which has helped me in real life.

## Handling a hard question

1. **Repeat the key noun:** *"When it comes to ______, …"*
2. **Give a qualified opinion:** *"I think it depends, but generally …"*
3. **Use a personal example.** You always have one.
4. **Close with a consequence.** *"So that is why I …"*

## Avoid

| Don't | Do |
|---|---|
| "Yes, I agree." (3 seconds) | Add reason, example, outcome |
| Repeat the same idea every question | Add a new angle each time |
| Use the same linker 6 times | Vary: *because, since, for instance, as a result* |
| Speak too fast and finish in 15 seconds | Slow down; develop the example |
| Ask the character to repeat | You cannot; answer what you heard |

## Checklist

- [ ] I clicked **Record** before speaking.
- [ ] Each answer was **25–35 seconds**.
- [ ] Each answer had **OREO** (or at least opinion + reason + example).
- [ ] I gave a **specific example**.
- [ ] I did not repeat the same idea across questions.
- [ ] I used a variety of linkers.
- [ ] I stayed on the question's topic.
