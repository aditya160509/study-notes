# DET Template Pack

Printable, fill-in templates for every productive task. Each file has: when to use it, a time budget, a skeleton, phrase bank, model, and a checklist.

These are **structures**, not scripts to memorise word-for-word. Duolingo penalises memorised, off-topic answers. Change the content every time.

## How to use a template

1. **Read the skeleton once.** Do not memorise whole sentences.
2. **Fill it with a real answer** about your own life, country or opinion.
3. **Record or time it.** Use the exact test time limit.
4. **Mark it** with the checklist at the bottom.
5. **Log the error** in [12-error-log.md](12-error-log.md).
6. **Repeat with a new prompt** the next day. Same structure, new content.

## The core structures

| Structure | Use | Parts |
|---|---|---|
| **3-sentence photo** | Write About the Photo | Summary → Action → Location |
| **5-step photo** | Speak About the Photo | Summary → Action → Location → Speculation → Detail |
| **PPF** | Read Then Speak, Speaking Sample | Present → Past → Future |
| **OREO** | Interactive Speaking | Opinion → Reason → Example → Outcome |
| **3-part paragraph** | Interactive Writing, Writing Sample | Topic → Support → Conclusion |

## Ground rules

- Answer the **exact** question. Off-topic scores badly even with good English.
- Use **full sentences** in writing.
- Leave **30–60 seconds** to proofread every written answer.
- Speak for **25–35 seconds** per Interactive Speaking question; **80–90 seconds** for long turns.
- Never invent wild details about a photo. Speculate only from visible evidence.
- The Writing and Speaking Samples go to universities. Treat them as application material.
